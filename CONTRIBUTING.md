# Contributing

openconformity is a hobby project maintained by one person, and it does not take code contributions for now. Feedback is welcome and shapes what comes next.

- **Bugs and ideas** go in [GitHub issues](https://github.com/omxnt/openconformity/issues). Say what you did, what you expected, what happened, and which browser you used.
- **Anything you would rather not post in public** goes to [info@openconformity.org](mailto:info@openconformity.org).
- **Security vulnerabilities** are never posted as an issue. They are reported privately, as [SECURITY.md](SECURITY.md) describes.

Never attach a project file that holds confidential work. If you would like to take part in more than feedback, write to the address above.
