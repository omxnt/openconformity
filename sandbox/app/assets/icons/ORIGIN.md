# Origin

IBM Carbon icons, vendored from the official package. The glyphs are inlined as
an SVG sprite in `index.html`; no file in this folder is loaded at runtime.

| Package | Version | Source |
|---|---|---|
| @carbon/icons | 11.85.0 | https://github.com/carbon-design-system/carbon/tree/main/packages/icons |

Each glyph is taken at its 16 px optical size where the package provides one,
and at 32 px otherwise. The symbol id in the sprite and the Carbon name it came
from are listed together there.

The SVG sources, and the full mapping from symbol id to Carbon name and size,
are in `sandbox/sources/icons/carbon/`.

No icon in this set is a company logo or a brand mark. Carbon publishes those
under `logo--*` names, and Apache 2.0 does not extend to the trademarks they
represent, so none of them is used.
