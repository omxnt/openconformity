# Origin

IBM Carbon icons, vendored from the official package. The glyphs are inlined
as an SVG sprite in `index.html`; no file in this folder is loaded at
runtime. The folder holds the repository source of every glyph the sprite
carries, and both grow as the interface does.

| Package | Version | Source |
|---|---|---|
| @carbon/icons | 11.85.0 | https://github.com/carbon-design-system/carbon/tree/main/packages/icons |

Each glyph is taken at its 16 px optical size where the package provides
one, and at 32 px otherwise. No icon in this set is a company logo or a
brand mark: Carbon publishes those under `logo--*` names, and the Apache 2.0
licence does not extend to the trademarks they represent, so none of them is
used.
