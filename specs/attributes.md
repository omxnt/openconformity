# Attributes

This document specifies the attributes each entity type carries. The metamodel defines the types and how they relate. An attribute not recorded here is not part of the model.

## 1. Conventions

### 1.1 Identifier

An identifier is generated by the software, never changed or reused, and is not an attribute. The file carries it beside the attributes.

### 1.2 Values

Every attribute is optional and every value is stored as text. An unset attribute is an absent key. An unset Applicable means not yet assessed. A computed attribute is never stored.

### 1.3 Kinds

Each attribute uses one of the kinds below.

| Kind | Meaning |
|---|---|
| text | A single line of text. |
| multiline | Text of any length, line breaks preserved. |
| choice | One value from the Values column. |
| set | Any number of the values in the Values column, stored as chosen, separated by semicolons in the column's order. |
| hyperlink | A web address. |
| number | A whole number within the bounds the Values column gives. |
| date | A calendar date, stored as its year, month and day, 2026-09-24. |
| drawing | SVG text, shown only as an image, accepted only after the drawing check the requirements state. |
| table | Rows of columns. The columns are the rows beneath whose key is the table's key, a dot and their own, each a text, a multiline, a date, a choice or a number. Stored as one line per row, cells parted by tabs and quoted as CSV where needed, empty rows dropped. |
| computed | Derived from the parameters beside it by the method the Values column names. Shown, never stored. |
| rationale | Why the class of the parameter the Values column names was chosen. |
| entities | The identifiers of the entities related by the relationship type the Values column names first, as they stood when the group it names second last changed. Written by the software, separated by semicolons in ascending order. |

### 1.4 Tabs and groups

A type's attributes stand on tabs, each a numbered `####` heading, in the editor's order. The first tab holds the type's own attributes and is named by the last word of the type's name. Every type ends with a Notes tab. A tab may hold groups, each a `#####` heading with its table. A group whose variants wait on a choice is a slot, and its variants stand under it as `######` headings, each carrying its tag. Keys are unique within a type. Tab and group names are stored in no file.

A group's heading may carry tags.

| Tag | Meaning |
|---|---|
| `when key = value` | Shown only while that attribute holds that value, and kept only then. A save made while hidden clears what it held, after a question. The key may be the project's where the type has none. |
| `when key =` | The same, while the attribute is unset. |
| `after key` | Stands after that attribute instead of after the one it waits on. |

One variant of a slot holds at a time. A group ending in a computed attribute is a rating.

### 1.5 Template

Each entity type is written as below. A sentence or two may stand under the type's heading where the tables cannot say it. A rating's parameters carry no help.

```
### 3.1 Entity Type (CODE)

#### 3.1.1 Type

| Attribute | Kind | Values | Help | Key |
|---|---|---|---|---|
| Name | kind | value; value | What it is, in one or two sentences. | key |

#### 3.1.2 Tab name

| Attribute | Kind | Values | Help | Key |
|---|---|---|---|---|
| Name | kind | value; value | What it is, in one or two sentences. | key |

##### Group name

###### Variant `when key = value`

| Attribute | Kind | Values | Help | Key |
|---|---|---|---|---|
| Name | kind | value; value | | key |

#### 3.1.3 Notes

| Attribute | Kind | Values | Help | Key |
|---|---|---|---|---|
| Notes | multiline | | Anything worth keeping that no field holds, such as how something was assessed. | notes |
```

### 1.6 Labels

The label is the reference and the title with a space between, or the title alone.

### 1.7 Shared help

Help stands in the Help column of each table. The names below have no row of their own, the identifier and the groups a rating or a level slot is named for, so their help is recorded here once.

| Name | Help |
|---|---|
| Identifier | Assigned by the tool from the entity type's code and a running number, never changed and never reused. |
| Initial risk estimation | The risk before protective measures, estimated by the method chosen or typed where none is. |
| Residual risk estimation | The risk with the protective measures in place, estimated by the method chosen or typed where none is. |
| Required integrity level | The level the safety function must reach, in its standard's own terms. |

## 6. Risk estimation

A scenario is rated by one of the three example methods of ISO/TR 14121-2:2012 [1], chosen on the project, or typed with no method. The level, index or score is read from the tables below wherever it is shown and never stored. The class definitions are the source's own, at the clause given, and are not reproduced here.

### 6.1 Risk matrix

ISO/TR 14121-2:2012, 6.2.2, Table 1. The severity across, the probability down.

| Probability | Catastrophic | Serious | Moderate | Minor |
|---|---|---|---|---|
| Very likely | High | High | High | Medium |
| Likely | High | High | Medium | Low |
| Unlikely | Medium | Medium | Low | Negligible |
| Remote | Low | Low | Negligible | Negligible |

### 6.2 Risk graph

ISO/TR 14121-2:2012, 6.3.2, Figures 3 and 4. Severity S and exposure F down, occurrence O and avoidance A across, giving a risk index from 1 to 6 with its band in the second table.

| S F | O1 A1 | O1 A2 | O2 A1 | O2 A2 | O3 A1 | O3 A2 |
|---|---|---|---|---|---|---|
| S1 F1 | 1 | 1 | 1 | 1 | 2 | 2 |
| S1 F2 | 1 | 1 | 1 | 1 | 2 | 2 |
| S2 F1 | 2 | 2 | 2 | 3 | 3 | 4 |
| S2 F2 | 3 | 4 | 4 | 5 | 5 | 6 |

| Risk index | Risk |
|---|---|
| 1; 2 | lowest |
| 3; 4 | medium |
| 5; 6 | highest |

### 6.3 Numerical scoring

ISO/TR 14121-2:2012, 6.4.2. The severity score SS and the probability score PS, each 0 to 100, add up to the risk score RS with its category in the third table. The first two tables give the class of a score.

| Severity score | Class |
|---|---|
| 100 | catastrophic |
| 90 – 99 | serious |
| 30 – 89 | moderate |
| 0 – 29 | minor |

| Probability score | Class |
|---|---|
| 100 | very likely |
| 70 – 99 | likely |
| 30 – 69 | unlikely |
| 0 – 29 | remote |

| From | To | Category |
|---|---|---|
| 160 | 200 | high |
| 120 | 159 | medium |
| 90 | 119 | low |
| 0 | 89 | negligible |
