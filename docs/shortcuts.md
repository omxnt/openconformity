# Shortcuts

The keys and modified clicks the software answers to, one table per place, with the key as a Mac keyboard writes it and as a PC keyboard writes it. N-ACC-003 requires full keyboard operability, and every action below has a keyboard path.

## 1. Everywhere

| Mac | PC | Does |
|---|---|---|
| ⌘S | Ctrl S | Saves the open edit, or the project to a file |
| ⌘Enter | Ctrl Enter | Finishes what is open. Saves an edit, relates the picks, applies a diagram. |
| ⌘Z | Ctrl Z | Undo |
| ⇧⌘Z | Ctrl Y, Shift Ctrl Z | Redo |
| ⌘F | Ctrl F | Focuses the tree's filter |
| Escape | Escape | Closes what is open, innermost first. A menu, a tooltip, a dialog, an edit, a mode. |
| Tab | Tab | Moves through the controls. A dialog keeps it inside. |

## 2. The menu bar

| Mac | PC | Does |
|---|---|---|
| Enter, Space, ↓ | Enter, Space, ↓ | Opens the focused menu |
| ← → | ← → | Walks the menus along the bar, open or not |
| ↑ ↓ | ↑ ↓ | Walks the entries |
| Home, End | Home, End | First and last entry |
| Enter, Space | Enter, Space | Runs the entry |

## 3. The tree

| Mac | PC | Does |
|---|---|---|
| ↑ ↓ | ↑ ↓ | Moves the selection |
| → | → | Opens the row, or moves into it |
| ← | ← | Closes the row, or moves to its parent |
| Home, End | Home, End | First and last row |
| Enter, Space, F2 | Enter, Space, F2 | Edits the selected entity, or renames the folder |
| ⌘⌫, Delete | Delete | Deletes the selection, asking first |
| ⌥↑ ⌥↓ | Alt ↑ Alt ↓ | Moves the selection among its siblings |
| ⇧F10 | Shift F10, Menu | Opens the context menu |
| Escape in the filter | Escape in the filter | Clears the filter |
| Double click | Double click | Edits the entity, or renames the folder |
| Drag | Drag | Files the row where it is dropped |

## 4. Picking relationships

| Mac | PC | Does |
|---|---|---|
| Click, Space | Click, Space | Picks or unpicks the row |
| ⇧click | Shift click | Applies the last click to the range |
| ⌘A | Ctrl A | Picks every candidate shown |
| ⌘Enter | Ctrl Enter | Done |
| Enter | Enter | Nothing |
| Escape | Escape | Leaves without relating |

## 5. The editor

| Mac | PC | Does |
|---|---|---|
| Enter, F2 on a row | Enter, F2 on a row | Begins the edit |
| ⌘S, ⌘Enter | Ctrl S, Ctrl Enter | Saves the edit, from a text area too |
| Escape | Escape | Cancels the edit, asking when it is dirty |
| Tab | Tab | Moves through the fields |
| ← → in the tab bar | ← → in the tab bar | Moves between the tabs |
| Enter, Space on a rating | Enter, Space on a rating | Opens the rating dialog |

## 6. The library

| Mac | PC | Does |
|---|---|---|
| ↑ ↓ | ↑ ↓ | Moves the highlight, the preview following |
| → ← | → ← | Opens and closes the row |
| Space, click on the box | Space, click on the box | Picks the row and what is beneath it |
| ⌥Space, ⌥click | Alt Space, Alt click | Picks the one entity, nothing beneath |
| Click on the text | Click on the text | Highlights the row, the preview following |
| Escape | Escape | Closes the picker |

## 7. Dialogs and the rest

| Mac | PC | Does |
|---|---|---|
| Enter in a dialog | Enter in a dialog | The primary action, unless the focus is in a text area |
| Escape in a dialog | Escape in a dialog | Cancel |
| ← → on a splitter | ← → on a splitter | Moves it 16 pixels |
| Double click on a splitter | Double click on a splitter | Returns it to its preset |
| Enter, Space on a table head | Enter, Space on a table head | Sorts by it |
| Enter, Space on a graph box | Enter, Space on a graph box | Selects the entity |
| ⌘Enter on a diagram | Ctrl Enter on a diagram | Apply |
| Escape on a diagram | Escape on a diagram | Cancels the diagram edit, asking when it is dirty |
